PATIENT RESOURCE GUIDELINES
===========================

This document contains specific guidelines for generating Patient resource data.

1. REQUIRED FIELDS
------------------
The following fields should always be populated:
- ID: Unique patient identifier
- NAME: At least one name with family and given
- GENDER: Valid gender code
- BIRTHDATE: Date of birth

2. IDENTIFIER ARRAY
-------------------
Each patient should have identifiers in this format:
[
  {"system": "MRN", "value": "MRN1234567890"},
  {"system": "SSN", "value": "123-45-6789"}
]

MRN Rules:
- Always starts with "MRN"
- Followed by 10 numeric digits
- Must be unique per patient

SSN Rules:
- Format: XXX-XX-XXXX
- Should be realistic looking (no 000, 666, or 900-999 in first group)
- Will be hashed in output for PHI protection

3. NAME ARRAY
-------------
Format:
[
  {
    "use": "official",
    "family": "Smith",
    "given": ["John", "Michael"],
    "prefix": ["Mr."],
    "suffix": []
  }
]

- "use" values: official, usual, nickname, maiden, old
- "given" is an array (first name, middle name)
- "family" is the last name (string)

4. ADDRESS ARRAY
----------------
Format:
[
  {
    "use": "home",
    "line": ["123 Main Street", "Apt 4B"],
    "city": "Houston",
    "state": "TX",
    "postalCode": "77001",
    "country": "USA"
  }
]

Texas ZIP code ranges:
- 75xxx: North Texas (Dallas area)
- 76xxx: North Central Texas (Fort Worth area)
- 77xxx: Southeast Texas (Houston area)
- 78xxx: South Texas (San Antonio, Austin area)
- 79xxx: West Texas (Lubbock, El Paso area)

5. TELECOM ARRAY
----------------
Format:
[
  {"system": "phone", "value": "555-123-4567", "use": "home"},
  {"system": "phone", "value": "555-987-6543", "use": "mobile"},
  {"system": "email", "value": "john.smith@email.com", "use": "home"}
]

- "system" values: phone, fax, email, pager, url, sms
- "use" values: home, work, temp, old, mobile

6. GENDER
---------
Valid values:
- male
- female
- other
- unknown

7. BIRTHDATE
------------
- Format: YYYY-MM-DD
- Must be a date in the past
- Should be realistic for the scenario
  - Pediatric: 0-18 years
  - Adult: 18-65 years
  - Elderly: 65+ years

8. MARITAL_STATUS
-----------------
Format:
{
  "coding": [
    {
      "system": "http://hl7.org/fhir/marital-status",
      "code": "M",
      "display": "Married"
    }
  ]
}

Valid codes:
- A: Annulled
- D: Divorced
- I: Interlocutory
- L: Legally Separated
- M: Married
- P: Polygamous
- S: Never Married (Single)
- T: Domestic Partner
- U: Unmarried
- W: Widowed
- UNK: Unknown

9. CONTACT (Emergency Contact)
------------------------------
Format:
[
  {
    "relationship": [{"text": "Spouse"}],
    "name": {"family": "Smith", "given": ["Jane"]},
    "telecom": [{"system": "phone", "value": "555-111-2222"}]
  }
]

10. COMMUNICATION
-----------------
Format:
[
  {
    "language": {
      "coding": [{"code": "en", "display": "English"}]
    },
    "preferred": true
  }
]

Common language codes:
- en: English
- es: Spanish
- zh: Chinese
- vi: Vietnamese
- ko: Korean
- tl: Tagalog
